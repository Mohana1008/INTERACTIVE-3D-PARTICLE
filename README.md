# Hand-Gesture 3D Particle System

A real-time, interactive 3D particle system built with Three.js that responds to your hand gestures via webcam. Morph particles between shapes (heart, flower, Saturn, fireworks, and more), control expansion/color with your hands, and watch it all render live in the browser.

## ✨ Features
- 🖐️ Webcam-based hand-tracking (no external servers — everything runs locally)
- 🎨 Dynamic particle shape-switching and color control
- 📱 Works on desktop and mobile, with touch-drag fallback controls
- ⚡ Optimized for low-power hardware (8GB RAM / integrated graphics)
- 🔒 Privacy-first: camera data never leaves your device, never stored, never sent anywhere
- 📖 Fully documented codebase — see `explanation.txt` for a beginner-friendly, line-by-line breakdown

## 🔐 Privacy & Security
This project processes all camera input locally in your browser. No video, images, or tracking data is ever uploaded, logged, or shared with any third party. Camera access requires explicit user permission and can be disabled at any time.
